# Chuleta de markdown

Los símbolos que necesitas para escribir en el idioma de la IA.

---

## Lo básico (el 90 % de lo que vas a usar)

| Escribes | Sale |
|---|---|
| `# Título` | Título grande |
| `## Apartado` | Subtítulo |
| `### Subapartado` | Subtítulo pequeño |
| `**negrita**` | **negrita** |
| `*cursiva*` | *cursiva* |
| `- elemento` | Lista con puntos |
| `1. elemento` | Lista numerada |

## Lo que viene bien saber

| Escribes | Sale |
|---|---|
| `> texto` | Cita o aviso destacado |
| `[texto](https://...)` | Un enlace |
| `---` | Línea separadora |
| `` `texto` `` | Texto tipo código |
| `- [ ] tarea` | Casilla sin marcar |
| `- [x] tarea` | Casilla marcada |

## Una tabla

```
| Columna 1 | Columna 2 |
|---|---|
| dato | dato |
```

---

## Las tres reglas para que salga bien

1. **Deja una línea en blanco** entre párrafos, listas y títulos.
2. **Pon un espacio** después de `#`, `-` y `>`.
3. **Un solo `#` por documento**: es el título principal. Para lo demás, `##` y `###`.

---

## Para trabajar con IA

- Las instrucciones y los documentos de contexto funcionan mejor en markdown: la IA entiende qué es principal y qué es secundario.
- Si al pegar una respuesta te salen asteriscos, pídele: "dámelo en texto plano, sin markdown".
- En Google Docs, activa markdown en Herramientas › Preferencias y se pegará con formato.
- Para abrir un `.md`: Bloc de notas (Windows) o TextEdit (Mac).
